\## CloudWork



The upstream projects are used as the initial infrastructure scaffold.



CloudWork will independently implement and redesign:



\- Multi-tenant SaaS architecture

\- Tenant and workspace management

\- Project collaboration

\- Task workflow

\- Kafka event-driven architecture

\- Notification service

\- Elasticsearch search service

\- MinIO file storage

\- Docker deployment

\- Kubernetes deployment

\- Observability and CI/CD
